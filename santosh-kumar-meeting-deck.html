My recent paper
v.

Compact multilingual AI on limited hardware

This first-author paper shows how I frame a problem, control an experiment, study errors, and report limits.

Research question

Can 4-bit QLoRA make small language models accurate across many languages while using less memory?

Study design

  • 42,000 balanced messages across 21 languages.
  • Compared Gemma 3, Qwen 3, and Llama 3.2.
  • Tested 16-bit, 4-bit, and 4-bit QLoRA stages.
  • Used the same training settings on one NVIDIA T4.

Main result and transferable skill

  • Gemma reached 90% accuracy and 0.88 F1.
  • Qwen and Llama fit below 4 GB after quantization.
  • Language-level analysis exposed uneven performance.
  • The same quality-cost-privacy tradeoff matters for wearable AI.

Proposed research directions

Practical AI for sensing and support

Four starting ideas that connect efficient models, wearable data, privacy, and safe agentic features.

Idea 1 - edge-ready behavior sensing

  • Measure speed, memory use, model size, and power needs.
  • Track person-level F1, false alarms, and missed events.
  • Build a small real-time wearable prototype.

Idea 2 - private personalization

Use lightweight local updates to adjust a shared model to each person without moving raw sensor data.

Idea 3 - agentic wearable support

  • Combine a sensor event with recent context and retrieved care rules.
  • Check confidence before the agent suggests an action.
  • Log the reason, evidence, and result for review.

Idea 4 - sensor data-to-knowledge

Build a reliable pipeline from long sensor streams to behavior events, quality checks, model monitoring, and clear research reports.
